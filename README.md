# 酒馆界面优化合集

面向 TauriTavern / SillyTavern 的四项界面改进，一个仓库一次安装。

## 安装

在酒馆 **扩展 → 安装扩展** 中粘贴：

```
https://github.com/moonxi2005/world-info-mobile-layout
```

安装后刷新酒馆，扩展名称为 **酒馆界面优化合集**。

如果已经安装旧的独立版本，请先在扩展管理中禁用以下四个旧扩展，再刷新：楼层快速导航、TopInfoBar Mobile Fix、提示词拆分 · 宽屏双栏、世界书 · 手机布局优化。同功能同时启用可能重复加载或导致样式覆盖。

本仓库的安装目录与旧的“世界书 · 手机布局优化”同名。如果安装器提示目录已存在，请先卸载旧世界书布局插件，再安装合集。只卸载插件本身，不要清除酒馆用户设置。

顶栏增强需要另外安装原版 [Chat Top Bar](https://github.com/SillyTavern/Extension-TopInfoBar)；保留这个原版插件，不要禁用。

## 包含功能

### 楼层导航

聊天左侧显示编号和圆点，用户和AI颜色不同。用户预览原文，AI优先已有摘要，无摘要则读取显示正则后的内容。点击定位楼层；按住“楼层”把手可以上下拖动，自动记住位置。扩展设置中可关闭或重置位置。

### 顶栏增强

聊天改名支持【随笔】【测试】【正文】快捷输入。齿轮可修改快捷词、总结模型及连接配置；默认模型名为 gemini-3.5-flash-lite，使用连接配置中已有的接口与密钥。

文档图标为当前聊天生成100字以内总结，长聊天分段处理，成功后保存。失败或取消保留旧总结。列表悬停显示独立预览，不改变行高；有总结显示总结，无总结则读取第一条非系统消息。

手机顶栏分两排：聊天名80%、搜索20%；第二排按钮分列左右。总结是点击时的快照，继续聊天后可重新生成。

### 提示词拆分双栏

电脑半屏窗口也能使用。弹窗四边仅留8像素；左侧统计，右侧正文，独立滚动及自动换行。兼容新旧弹窗，保留复制和差异功能。手机沿用原生窗口。

### 手机世界书布局

条目名独占完整一行；状态及操作按钮放下一行，位置独占一行，深度/顺序/概率并排。顶部文件操作、搜索排序重新分行。原生控件和数据保留。

手机布局仅在视口与屏幕宽度均不超过600 CSS像素且主指针为触屏时启用，电脑窄窗口和平板分屏不启用。

## 数据与兼容性

本仓库仅包含界面插件代码，不含角色卡、聊天、预设、模型配置或密钥。原独立插件的本地位置与总结设置继续沿用。

总结功能仅在点击时向选定连接发送整理后的聊天材料；模型服务可能拒绝内容，需使用支持相应内容的模型及连接。首条消息预览只读取本地聊天接口，不调用模型。

不同主题和酒馆版本可能影响布局。禁用合集并刷新即可恢复原界面。扩展管理中的更新按钮可获取后续版本。
